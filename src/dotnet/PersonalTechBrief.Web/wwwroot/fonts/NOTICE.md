# Self-hosted web fonts

These fonts back the retro-editorial UI theme in `wwwroot/app.css`. They are
served from this folder (no external CDN) so the app has no third-party font
dependency and leaks no viewer IPs at load time.

Both families are licensed under the SIL Open Font License 1.1
(https://scripts.sil.org/OFL), which permits bundling and redistribution.
